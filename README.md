# javascript-lotto-precourse

### 프로그램 설명
- 사용자의 구입 금액, 당첨 번호, 보너스 번호를 입력받아 로또 게임의 당첨 결과와 총 수익률을 계산한다.

### 기능 목록
- 구입 금액을 입력 받는다.
- 구입 금액에 따라 구매 가능한 로또 개수를 계산한다.
- 계산된 개수만큼 로또 번호를 자동으로 생성한다.
- 생성된 로또 번호를 한 줄씩 출력한다. 
- 당첨 번호를 입력 받는다.
- 보너스 번호를 입력 받는다.
- 당첨 번호와 보너스 번호를 기준으로 당첨 결과를 판별한다.
- 당첨 결과를 출력한다.
- 구입 금액과 당첨금으로 수익률을 계산한다.
- 총 수익륙을 출력한다.

### 예외 상황 목록
- 구입 금액을 입력하지 않은 경우
- 구입 금액이 1,000원 미만인 경우
- 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우
- 당첨 번호를 입력하지 않은 경우
- 당첨 번호의 갯수가 6개가 아닌 경우
- 당첨 번호가 1에서 45 사이의 숫자가 아닌 경우
- 당첨 번호에 중복된 숫자가 존재하는 경우
- 보너스 번호를 입력하지 않은 경우
- 보너스 번호가 1에서 45 사이의 숫자가 아닌 경우
- 보너스 번호가 당첨 번호와 중복되는 경우
- 보너스 번호의 갯수가 여러 개 입력된 경우

### 파일 설명

1. App.js

   -   프로그램의 메인 컨트롤러 역할.
   -   domain/view/utils의 클래스들을 조율하여 로또 게임의 전체 흐름을 관리한다.

2. domain (핵심 로직)

   -   **Lotto.js**: 로또 1장의 번호(6자리)를 다루는 도메인 객체. 생성 시점에 6자리, 중복, 숫자 범위에 대한 유효성 검사를 스스로 수행한다.
   -   **Bonus.js**: 보너스 번호 1개를 다루는 도메인 객체. 생성 시점에 숫자 범위 유효성 검사를 수행한다.
   -   **PurchaseAmount.js**: 구입 금액을 다루는 도메인 객체. 생성 시점에 1000원 단위, 최소 금액 유효성 검사를 수행하며, 구매 개수를 계산하는 getter를 제공한다.
   -   **LottoGame.js**: 당첨 번호, 보너스 번호, 구매한 로또 목록을 받아 당첨 순위를 판별한다.
   -   **LottoResult.js**: LottoGame이 판별한 순위 목록을 받아 통계를 집계하고, 총 수익률을 계산한다.

3. view (입출력)

   -   **Input.js**: 사용자의 입력을 받는 static 메서드들을 제공한다. (구입 금액, 당첨 번호, 보너스 번호 입력)
   -   **Output.js**: 사용자에게 결과를 출력하는 static 메서드들을 제공한다. (구매 개수, 로또 목록, 당첨 통계, 수익률 출력)

4. utils

   -   **LottoGenerator.js**: 중복되지 않는 랜덤 6개 숫자로 구성된 로또 번호를 1개 또는 여러개 생성한다.
   -   **Constants.js**: ERROR_MESSAGES, OUTPUT_MESSAGES, RANK 등 프로그램에서 사용되는 모든 상수를 모아 관리한다.
