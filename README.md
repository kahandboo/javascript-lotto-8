# javascript-lotto-precourse

### 프로그램 설명
- 사용자의 구입 금액, 당첨 번호, 보너스 번호를 입력받아 로또 게임의 당첨 결과와 총 수익률을 계산한다.
### 기능 목록
- 구입 금액을 입력 받는다.
- 구입 금액에 따라 구매 가능한 로또 개수를 계산한다.
- 계산된 개수만큼 로또 번호를 자동으로 생성한다.
- 생성된 로또 번호를 한 줄씩 출력한다. 
- 당첨 번호를 입력 받는다.
- 보너스 번호를 입력 받는다.
- 당첨 번호와 보너스 번호를 기준으로 당첨 결과를 판별한다.
- 당첨 결과를 출력한다.
- 구입 금액과 당첨금으로 수익률을 계산한다.
- 총 수익륙을 출력한다.

### 예외 상황 목록
- 구입 금액을 입력하지 않은 경우
- 구입 금액이 1,000원 미만인 경우
- 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우
- 당첨 번호를 입력하지 않은 경우
- 당첨 번호의 갯수가 6개가 아닌 경우
- 당첨 번호가 1에서 45 사이의 숫자가 아닌 경우
- 당첨 번호에 중복된 숫자가 존재하는 경우
- 보너스 번호를 입력하지 않은 경우
- 보너스 번호가 1에서 45 사이의 숫자가 아닌 경우
- 보너스 번호가 당첨 번호와 중복되는 경우
- 보너스 번호의 갯수가 여러 개 입력된 경우
